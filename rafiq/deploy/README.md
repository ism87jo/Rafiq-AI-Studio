# استضافة Rafiq AI Studio

هذه حزمة استضافة خاصة لمؤسسة رفيق البصيرة. تفتح الواجهة عبر HTTPS وتطلب اسم مستخدم وكلمة مرور قبل عرض المشاريع أو الوسائط. كل من يستخدم الحساب نفسه يستطيع الوصول إلى المشاريع نفسها.

1. استخدم خادم Linux متاحًا لديك عليه Docker Compose، ووجّه نطاقًا فرعيًا مخصصًا إلى عنوانه. يجب أن يصل الإنترنت إلى المنفذين 80 و443 حتى يصدر Caddy شهادة HTTPS. إذا كان الخادم يستضيف مواقع أخرى على هذين المنفذين، اربط التطبيق بموجّه HTTPS الحالي بدل تشغيل موزّع منافذ ثانٍ.
2. من مجلد `rafiq/deploy` انسخ `.env.example` إلى `.env` واضبط `STUDIO_HOST` و`STUDIO_USER`. أنشئ بصمة كلمة مرور قوية بالأمر `docker run --rm -it caddy:2-alpine caddy hash-password`. ضع البصمة بين علامتي اقتباس مفردتين في `.env`.
3. شغّل `docker compose up --build -d`، ثم افتح نطاق الاستوديو عبر HTTPS وأدخل بيانات الدخول.
4. تحقّق من غلق الوصول بدون تسجيل الدخول وجرّب حفظ مشروع، ورفع فيديو، وتصدير MP4 بعد اختيار اللقطة.

يُحفظ SQLite والوسائط في وحدة التخزين `studio_data`. يتطلب النسخ الاحتياطي الكامل إيقاف خدمة الاستوديو مؤقتًا ثم نسخ كامل المجلد، بما فيه الوسائط، قبل إعادة تشغيلها. احتفظ بالنسخة الاحتياطية خارج الخادم واختبر استعادتها قبل الاعتماد على الموقع في الإنتاج.

حزمة الاستضافة تشغّل إدارة المشروعات والمونتاج والتصدير. للتوليد استخدم زر تجهيز المشهد لجهاز GPU، ثم استورد الناتج من صفحة الإنتاج والتصدير. نجح اختبار Wan 2.1 على T4 منفصل. تشغيل موقع عام لعدة مستخدمين يحتاج حسابات مستقلة وعزل بيانات وطابور GPU قبل اعتماده.
